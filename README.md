## Run locally

1. Clone the repository:
   `git clone https://github.com/sabarishv544-glitch/Portfolio.git`
2. Move into the project:
   `cd Portfolio`
3. Install dependencies:
   `npm install`
4. Start the development server:
   `npm start`
5. Open [http://localhost:3000](http://localhost:3000).

Create a production build with:

`npm run build`

## Customize

Update the project list, skills, and GitHub URL in `src/App.js`. Global colors, layout, and responsive styles are in `src/style.css`.
